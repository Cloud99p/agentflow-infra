## Reproducing These Screenshots

They are generated, not hand-taken:

```bash
# 1. Start the dashboard
npm run dashboard

# 2. Capture (fails if the API is not serving live data)
node scripts/capture-screenshots.mjs http://localhost:3000
```

The capture script refuses to run when `/api/market-data` returns
`isLive: false`, and writes a manifest recording what was on screen.

## Notes

- Prices come from **CoinGecko → Binance → Bitget failover** — not Bitget alone.
  `api.bitget.com` is DNS-blocked from some ISPs, which is what caused the
  original silent fallback to mock data.
- Portfolio state lives in `portfolio_state.json` and starts empty and honest.
- The **Sentiment** signal has no configured live source. It reports a neutral
  score and labels itself `unavailable` rather than inventing a reading.
- There is no simulated fallback anywhere in the dashboard. When every live
  source fails the API returns HTTP 503 and the badge turns red.
